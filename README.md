# RFMiD Multi-Disease Retinal AI

A research prototype for multi-label retinal disease classification
using a ResNet-50 model trained on the RFMiD dataset.

## Model

- Architecture: ResNet-50
- Input size: 224 x 224
- Number of disease classes: 45
- Output: Multi-label disease probabilities
- Activation: Sigmoid
- Classification threshold: 0.5

## Important Notice

This application is a research and educational prototype.

It is NOT a medical diagnostic tool and should not be used
for clinical diagnosis or treatment decisions.

## Deployment

The application is designed to run as a Python web service on Render.
